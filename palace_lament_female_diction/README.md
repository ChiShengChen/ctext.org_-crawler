# 宮怨詩 vs 女性詩人 — 用語差異分析

比較《全唐詩》中**宮怨詩(多為男性代言宮中女子)**與**女性詩人親筆詩**的用語差別，
並將女性自述進一步拆成**宮詞記事**與**閨怨抒情**，對照**代言 vs 自述**的措辭差異。

## 研究問題

1. 宮怨詩(男性主導的題材)與女性詩人在用字上有何系統差別?
2. 女性自己寫宮/閨題材時，措辭是否不同於男性代言?(代言 vs 自述)
3. 女性自述中，**記事**(宮詞)與**抒情**(閨怨)兩種模式的用語差異?

## 分組

| 組別 | 定義 | 來源 |
|------|------|------|
| **G1** 宮怨詩 | 宮怨詩名單所列、且比對到語料之詩 | `data/data_index/*.csv` |
| **G1m** 宮怨詩・代言 | G1 中 `性別=男`(男性/代言) | 自動 |
| **G2** 女性詩人 | 女性詩人名下全部詩 | 名單 `性別=女` ∪ `data/female_poets.txt` |
| **G3** 女性自述 | 女性所寫宮/閨題材(名單女性 + 標題關鍵字擴充) | 自動 |
| ├ **G3d** 宮詞記事 | 宮詞／宮中，或含宮苑葉之「題…」題壁（排除題寺/景/應制）| 自動 |
| └ **G3l** 閨怨抒情 | 標題含 閨怨／春怨／長門／團扇／妾… | 自動 |

核心對照:**G1 vs G2**、**G1m vs G3l**(代言 vs 女性閨怨，同哀怨體)、**G3d vs G3l**。

## 名單格式

宮怨詩名單放在 `data/data_index/`，每列 `作者,性別,題目,…`（多 sheet 亦可；無題目的列，
如選本名稱清單，會自動略過）。標題有樂府前綴（`雜曲歌辭-…`）、首句後綴（`宮詞-故國三千里`）、
異體字（倢伃↔婕妤、臺↔台）皆由 `corpus.py` 的標題正規化處理，命中率約 **89%**。
`data/female_poets.txt` 為**補入的知名女詩人**（薛濤、魚玄機、李冶…），擴大 G2 代表性。

## 方法

- 斷詞:漢字 **1–2 gram**。
- 區辨詞:**Monroe et al. (2008) 加權 log-odds ratio + informative Dirichlet prior**
  （背景先驗＝全唐詩全集），對高低頻皆穩健;z 值愈大愈偏用該詞。
- 可解釋對比:五個**宮怨語彙場**（怨情／時序／宮殿空間／服飾器物／君恩）每萬字頻率。

## 使用

```bash
python3 corpus.py            # 確認語料解析（詩數、作者、標題）
python3 analyze_diction.py   # 三組對照 + 語彙場 → diction_report.md, unmatched_list.csv
python3 make_figures.py            # 用語圖表 -> figures/
python3 make_figures.py --lang en  # 英文標題 -> figures_en/
python3 analyze_syntax.py --figures            # 句式・詞性 -> syntax_report.md + fig5–7
python3 analyze_syntax.py --figures --lang en  # 英文標籤 -> figures_en/
```

## 主要發現（見 `diction_report.md`）

- **宮怨詩(男性主導)** 偏用**典故化宮廷詞彙**:長門／昭陽／長信／金屋／團扇／飛燕／
  君恩／承恩／妒／棄妾（陳皇后、班婕妤、趙飛燕、阿嬌等 exempla）。
- **女性詩人** 偏用**個人化情感/文學語彙**:郎／儂／相思／紅箋／詩／吟／同心／離。
- **代言 vs 自述**:差別主要在**手法**——男性代言重用典與宮廷空間，女性自述較直述。
- **拆子類後的修正**:先前「男性代言比女性更哀怨」是把**哀怨體 vs 記事體**混比的假象;
  一旦**哀怨 vs 哀怨**(G1m 代言 vs G3l 閨怨)，女性閨怨的怨情/君恩語彙場**更飽和**
  (怨情每萬字 312 vs 169、君恩 409 vs 243)。宮詞記事(G3d)則是低哀怨、重宮廷實景的另一模式。

> ⚠️ **限制**:G3l(女性閨怨)n≈11、G3d(宮詞記事)n=4，樣本小，區辨詞 z 值偏弱，
> 結論屬 suggestive;G3d **以字數計 99% 為花蕊夫人《宮詞》一人**,≈個人樣本、不宜當子類解讀。
> 未比對 45 筆(語料未爬到之卷、
> 作者不在語料)見 `unmatched_list.csv`。

## 句式・詞性用法（見 `syntax_report.md`）

文言無可靠 POS 標註器，故以**結構特徵**（句式）與**古漢語虛詞詞類**（詞性）分析。

- **詩形**:女性詩人明顯偏**七言**（68% vs 代言 53%）;宮詞（花蕊夫人）偏五言。
- **二人稱「君/爾」**:男性代言最高（每萬字 122 vs 女詩人 67）——代言宮怨是**對「君」的
  傾訴**（妾↔君），結構上是一封對上位者的陳情。
- **問句率**:代言（5.9/100 句）與閨怨（5.6）高，宮詞（2.0）低——哀怨體多**詰問語氣**，
  記事體幾乎不問。
- **語氣助詞（兮/矣/乎/哉）**:女性書寫較多（閨怨 48、女詩人 38 vs 代言 18、宮詞 2），
  情感語氣更外顯。
- **副詞・時間詞・否定**:閨怨最密（副詞 312、時間 288）——女性閨怨的**時間流逝與否定/
  猶尚**語氣最重。

> ⚠️ 宮詞（G3d）的「句數/首＝160」是語料結構假象（花蕊夫人《宮詞》整組併為一筆），
> 篇幅一欄不可直接解讀;其餘每字/每句比率不受影響。句式/虛詞小樣本波動大，屬 suggestive。
