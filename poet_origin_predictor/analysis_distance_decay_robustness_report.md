# 距離衰減／Periphery 穩健性檢驗報告

由 [`analysis_distance_decay_robustness.py`](analysis_distance_decay_robustness.py) 產生
（資料：`dataset.csv`，357 詩人；距離衰減配置為每道 ≥5 詩人、≥10 首 → 9 個道；
seed=42，Mantel 置換 10,000 次）。本報告佐證論文「Distance decay」與
「Jiangnan vs. the center」兩節的修訂主張。

## 為何需要這份檢驗

審稿人對小樣本地理相關最常戳兩點：

1. **顯著性是否誠實。** 36 對「道—道」距離**並非獨立**，所以散點圖上 matplotlib
   印的 naive Pearson p 會低估不確定性。有效的檢定是 **Mantel 置換檢定**。
2. **是否被單一離群點（江南道）帶起來。** 逐一剔除每個道重新擬合即可檢驗。

---

## 1. 距離衰減（地理距離 × 語言距離 1−cosine）

```
FULL（9 道，36 配對）：  r = +0.400 | naive p = 0.016 | Mantel p = 0.093
```

**圖上的 0.016 是 naive p；正確值是 Mantel p ≈ 0.09。**

### Leave-one-circuit-out（每次剔除一個道後重擬合）

| 剔除的道 | r | naive p | Mantel p |
|---------|----:|----:|----:|
| 劍南道 | +0.454 | 0.015 | 0.074 |
| 山南道 | +0.532 | 0.004 | 0.041 |
| 嶺南道 | +0.244 | 0.211 | 0.326 |
| **江南道** | **+0.598** | **0.001** | **0.020** |
| 河北道 | +0.334 | 0.083 | 0.185 |
| 河南道 | +0.346 | 0.072 | 0.121 |
| 河東道 | +0.296 | 0.126 | 0.245 |
| 淮南道 | +0.361 | 0.059 | 0.245 |
| 關內道 | +0.401 | 0.035 | 0.105 |

**判讀：距離衰減穩健。** r 在所有剔除下**全程為正**（+0.24 ~ +0.60），無任何道翻轉
符號。尤其**剔除江南道後相關反而變強**（r 0.40 → 0.60、Mantel p 0.09 → 0.02），
與「被江南離群點帶起」的假象**正好相反**。

## 2. Periphery（辨識率 recall × 離長安距離）

| 道 | 離長安(km) | recall |
|------|----:|----:|
| 關內道 | 0 | 0.146 |
| 山南道 | 248 | 0.000 |
| 河南道 | 434 | 0.125 |
| 河東道 | 515 | 0.318 |
| 劍南道 | 609 | 0.000 |
| 河北道 | 649 | 0.043 |
| 淮南道 | 994 | 0.000 |
| 江南道 | 1142 | **0.635** |
| 嶺南道 | 1307 | 0.000 |

```
FULL：        Pearson r = +0.193 (p = 0.618) | Spearman rho = -0.148 (p = 0.704)
drop Jiangnan：Pearson r = -0.400 (p = 0.326) | Spearman rho = -0.507 (p = 0.199)
```

**判讀：「離首都越遠越易辨識」不成立。**

- 全樣本就**不顯著**（p > 0.3；用 ≥8 詩人的 6 道版亦僅 r≈0.46, p=0.36）。
- **去掉江南道後符號翻負**（r 翻成 −0.40、Spearman −0.51）。
- 結構性反證：**最遠的嶺南道（1307 km）recall = 0**，而高 recall 只有江南一點。

整條「距離梯度」其實是江南單點撐起。故論文已將此節改寫為
**「江南 vs. 中心」的混淆結構**（江南突出、中心關內/河南互相混淆），不作距離梯度解讀。

| 主張 | 處置 |

| 距離衰減 r=0.40 | **保留並加強**：報 Mantel p≈0.09（非 naive 0.016）、附 leave-one-out，明說去江南更顯著 |
| 「邊陲越遠越易辨識」 | **撤下距離梯度框架**，改為江南 vs. 中心對比；fig11 移除回歸線、改中性標題與誠實 caption |
