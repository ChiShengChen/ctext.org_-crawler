## 結論與啟示

1. **高度集中化**: 少數頂級詩人佔據了絕大部分詩歌產量，呈現明顯的「長尾分布」特徵。

2. **邊緣化現象**: 超過一半的詩人僅有一首作品被收錄，反映了文學傳承的選擇性。

3. **地理集中**: 某些地區（如關內道、江南道）的詩人密度較高，可能與政治、經濟、文化中心有關。

4. **職業多樣性**: 詩人背景多樣，包括官員、僧人、隱士等，反映了唐代文學的社會基礎。

5. **歷史選擇性**: 《全唐詩》的編纂反映了清代學者對唐代文學的價值判斷，具有明顯的歷史選擇性。

6. **數據驗證**: 通過與文章數據對比，證實了文學集中化現象的存在，但具體數值因統計方法不同而有所差異。
